# سایت ناصری | Naseri — نسخه آماده انتشار (نسخه ۲ با پنل مدیریت کامل)

سایت شخصی محمود ناصری برای معرفی و فروش اپلیکیشن‌های موبایل (Next.js 16 + TypeScript + Prisma + PostgreSQL).

## انتشار روی Vercel (رایگان)
راهنمای کامل قدم‌به‌قدم فارسی: فایل «راهنمای-انتشار-سایت-ورسل.docx»

خلاصه مسیر:
1. آپلود این فایل‌ها در یک مخزن GitHub (روی نسخه قبلی بریزید و Push کنید)
2. پروژه Vercel به‌صورت خودکار دوباره Build و منتشر می‌کند
3. جدول‌های جدید در اولین Build داخل دیتابیس Neon ساخته می‌شوند — داده‌های فعلی حفظ می‌شود

## پنل مدیریت (نسخه ۲)
آدرس مستقیم: `https://mahmoudnaseri.vercel.app/admin` — یا از فوتر سایت روی «مدیریت سایت» کلیک کنید.
- رمز اولیه: `naseri1404` (اگر قبلاً عوضش کردید، همان رمز جدید کار می‌کند)
- بخش‌های پنل:
  - **داشبورد** — آمار کلی و میان‌برها
  - **اپلیکیشن‌ها** — انتشار/مخفی‌کردن، افزودن/ویرایش/حذف
  - **باکس‌های محتوا** — ساخت باکس دلخواه با عکس، ویدیو، متن دو زبانه و دکمه
  - **رسانه‌ها** — کتابخانه آپلود عکس (تا ۲٫۵ مگابایت) و ویدیو (تا ۳ مگابایت)
  - **متن‌های سایت** — ویرایش همه متن‌های صفحه اصلی (فارسی و انگلیسی)
  - **بنر، لوگو و موشن** — لوگوی هدر/فوتر، بنر بالای سایت، تصویر «درباره من» و ویدیو موشن گرافیک (آپلود یا لینک آپارات/یوتیوب)
  - **اطلاعات تماس** و **امنیت** (تغییر رمز)

## توسعه محلی (اختیاری)
```bash
bun install
# یک دیتابیس PostgreSQL محلی و متغیر DATABASE_URL در فایل .env لازم است
bun run dev
```
